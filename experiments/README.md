# Additional experiments

- `quora/` generates the QuoraRetrieval rows.
- `efficiency/` measures direct evaluation and prediction time.
- `model_selection/` generates the 25,872 pairwise choices.
- `other_indexes/` collects and evaluates NSG and Vamana costs.

Run the main pipeline first. Commands are in each folder. Generated files go to
`artifacts/`; reported tables are in `results/`.
